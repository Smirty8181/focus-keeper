# Focus Keeper

Утилита для Windows, которая удерживает несколько окон «в фокусе» одновременно — например, для локального кооператива в двух экземплярах одной игры (запущенных через Sandboxie Plus и т. п.).

## Как работает

1. Окно «Клавиатура + мышь» получает настоящий передний план.
2. Окно с геймпадом дополнительно патчится: в процессе игры `GetForegroundWindow` / `GetActiveWindow` / `GetFocus` всегда возвращают его окно — игра «думает», что окно активно и не ставит себя на паузу. Для окна клавиатуры+мыши отключается XInput, чтобы геймпад им не управлял.
3. Остальные окна получают поддельный фокус через сообщения `WM_ACTIVATE` / `WM_ACTIVATEAPP` / `WM_NCACTIVATE` / `WM_SETFOCUS`.
4. Состояние геймпадов отображается в реальном времени (XInput), у каждого окна своё назначенное устройство.

## Горячие клавиши (глобальные)

| Клавиша | Действие |
|---------|----------|
| F8 | Включить / выключить удержание фокуса |
| F9 | Поменять устройства местами (клава/мышь ↔ геймпад) |

## Требования

- Только **Windows**
- Python 3.x (tkinter входит в состав)
- Запуск от имени **администратора** (иначе нельзя слать сообщения окнам с повышенными правами и патчить чужой процесс)

## Быстрый старт

```bash
python focus_keeper.py
```

1. Выберите окна в списке слева (или нажмите «Автопоиск игры»).
2. Назначьте каждому окну устройство.
3. Нажмите **СТАРТ (F8)**.

Настройки сохраняются в `focus_keeper_config.json`. Пример конфига: `focus_keeper_config.example.json`.

## Подготовка к публикации

В репозитории исключены из отслеживания:
- `__pycache__/` и `*.pyc` — байт-код Python
- `focus_keeper_modules.txt` — отладочный дамп модулей игровых процессов, создаётся программой во время работы
- `focus_keeper_config.json` — персональная конфигурация (свои окна и устройства)

## ⚠️ Предупреждение

Программа патчит память чужого игрового процесса (подменяет адреса функций в другом процессе через WinAPI). Используйте её только на своих устройствах и в рамках собственного тестирования / личного использования.
